# Phone Link — نسخه شروع (اندروید + داشبورد ویندوز)

این پروژه یک نمونه اولیه است: اپ اندروید اعلان‌های قابل‌مشاهده را با مجوز ویژه‌ی Notification Access می‌خواند و از طریق WebSocket به داشبورد ویندوز می‌فرستد. داشبورد در مرورگر ویندوز باز می‌شود و نیازی به نصب برنامه روی ویندوز ندارد.

## فایل‌ها
- `app/`: سورس اپ اندروید
- `relay/`: سرور واسط و داشبورد ویندوز
- `.github/workflows/build-apk.yml`: ساخت APK خودکار با GitHub Actions (بدون نصب Android Studio روی کامپیوتر)

## راه ساده ساخت APK بدون Android Studio
1. یک مخزن جدید در GitHub بساز و محتویات این پوشه را در آن قرار بده.
2. در GitHub به تب **Actions** برو.
3. گردش‌کار **Build Android APK** را انتخاب و روی **Run workflow** بزن.
4. بعد از پایان موفق، در بخش **Artifacts** فایل `PhoneLink-debug-apk` را دانلود و ZIP آن را باز کن؛ فایل `app-debug.apk` داخل آن است.
5. APK را به گوشی منتقل و نصب کن. اندروید ممکن است اجازه نصب از منبع ناشناس را بخواهد.

## راه‌اندازی سرور
پوشه `relay` باید روی یک میزبان Node.js که WebSocket را پشتیبانی می‌کند منتشر شود. دستور اجرا:
```bash
npm install
npm start
```
میزبان باید HTTPS/WSS ارائه کند. سپس آدرس WebSocket را به شکل `wss://your-domain.example` در اپ گوشی وارد کن و همان دامنه را در مرورگر ویندوز باز کن. برای تست محلی، در گوشی آدرس `ws://IP-کامپیوتر:3000` را وارد کن و داشبورد را در `http://IP-کامپیوتر:3000` باز کن؛ هر دو دستگاه باید روی یک شبکه باشند.

## اتصال
1. در داشبورد ویندوز یک کد تصادفی ۱۲ کاراکتری انتخاب کن.
2. همان کد را در اپ گوشی و داشبورد وارد کن.
3. در اپ گوشی آدرس سرور را وارد و تنظیمات را ذخیره کن.
4. گزینه «فعال‌کردن دسترسی اعلان‌ها» را بزن و در تنظیمات اندروید، دسترسی Phone Link را فعال کن.
5. اعلان‌های جدید باید در داشبورد ظاهر شوند. اعلان‌های قبلی بازیابی نمی‌شوند.

## محدودیت‌ها و امنیت
- فقط اعلان‌هایی منتقل می‌شوند که برنامه مبدأ در اعلان اندروید نمایش داده باشد؛ پیام کامل تاریخچه SMS/واتساپ/تلگرام خوانده نمی‌شود.
- پاسخ دادن به پیام‌ها در این نسخه وجود ندارد.
- انتقال فقط وقتی انجام می‌شود که اپ و داشبورد به سرور وصل باشند؛ پیام‌ها در سرور ذخیره یا در زمان قطع اتصال صف نمی‌شوند.
- از HTTPS/WSS و سرور شخصی استفاده کن. `ws://` فقط برای آزمایش در شبکه محلی است.
- کد اتصال را محرمانه نگه دار؛ هر دارنده کد می‌تواند اعلان‌ها را ببیند.
- اعلان‌ها ممکن است شامل رمز یک‌بارمصرف، اطلاعات بانکی یا پیام خصوصی باشند. فقط برنامه‌ها و اعلان‌هایی را مجاز کن که واقعاً لازم داری.
- این پروژه نمونه اولیه است و هنوز ممیزی امنیتی یا انتشار فروشگاهی نشده است.
