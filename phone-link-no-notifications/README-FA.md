# Phone Link — نسخه شروع (اندروید + داشبورد ویندوز)

این پروژه نسخه پایه Phone Link است. قابلیت خواندن و انتقال اعلان‌های گوشی از این نسخه حذف شده است. داشبورد در مرورگر ویندوز باز می‌شود و نیازی به نصب برنامه روی ویندوز ندارد.

## فایل‌ها
- `app/`: سورس اپ اندروید
- `relay/`: سرور واسط و داشبورد ویندوز
- `.github/workflows/build-apk.yml`: ساخت APK خودکار با GitHub Actions (بدون نصب Android Studio روی کامپیوتر)

## راه ساده ساخت APK بدون Android Studio
1. یک مخزن جدید در GitHub بساز و محتویات این پوشه را در آن قرار بده.
2. در GitHub به تب **Actions** برو.
3. گردش‌کار **Build Android APK** را انتخاب و روی **Run workflow** بزن.
4. بعد از پایان موفق، در بخش **Artifacts** فایل `PhoneLink-debug-apk` را دانلود و ZIP آن را باز کن؛ فایل `app-debug.apk` داخل آن است.
5. APK را به گوشی منتقل و نصب کن. اندروید ممکن است اجازه نصب از منبع ناشناس را بخواهد.

## راه‌اندازی سرور
پوشه `relay` باید روی یک میزبان Node.js که WebSocket را پشتیبانی می‌کند منتشر شود. دستور اجرا:
```bash
npm install
npm start
```
میزبان باید HTTPS/WSS ارائه کند. سپس آدرس WebSocket را به شکل `wss://your-domain.example` در اپ گوشی وارد کن و همان دامنه را در مرورگر ویندوز باز کن. برای تست محلی، در گوشی آدرس `ws://IP-کامپیوتر:3000` را وارد کن و داشبورد را در `http://IP-کامپیوتر:3000` باز کن؛ هر دو دستگاه باید روی یک شبکه باشند.
